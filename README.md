# Maturitní ples – ukázka webu

Ukázka webu pro maturitní ples od **[MadeByEmKo](https://madebyemko.cz)**. Třída, škola, jména, místo i sponzoři jsou smyšlené.

**Živá ukázka:** https://madebyemko.github.io/ples/

## Co web obsahuje

- úvod s odpočtem do plesu
- program večera od otevření sálu po afterparty
- vstupenky a rezervace konkrétních míst v plánku sálu, včetně ceny za celý stůl
- představení třídy a třídní učitelky
- tombola s hlavními cenami a poděkování sponzorům
- vzkazy pro maturanty od rodiny, kamarádů a učitelů
- galerie fotek a odkaz na sdílené album
- místo, doprava, parkování a časté dotazy
- kontakty na organizační tým

V ukázce se rezervace a vzkazy ukládají jen v prohlížeči návštěvníka. Ve verzi pro skutečný ples vidí obsazená místa všichni hosté a potvrzení rezervace s platebními údaji přichází e-mailem.

## Technologie

Jeden soubor HTML, CSS a JavaScript bez knihoven. Rychlé načtení a přehledné zobrazení na mobilu.
